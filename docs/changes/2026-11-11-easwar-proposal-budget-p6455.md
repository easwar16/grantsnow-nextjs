# P_6455 Budget scope and layout

- **Date / scope:** 2026-11-11, active Next.js worktree. The VBCS `origin/development` checkout and signed-in VBCS and local DEV preview were read-only references.
- **Why:** P_6455 Budget loaded in VBCS but Next.js rejected a child Budget line as outside scope. The half-width toolbar, header field order, AI/Compare icons, Budget column widths, and Show Year Split control also differed from VBCS.
- **Data fix:** The Budget mapper now accepts a child row only when its Proposal number occurs among the freshly authorized Summary's attached Sub-Proposals. It still rejects unrelated Proposal rows. Live local DEV P_6455 now displays the parent and child cost trees, including Staff, Infra, Estates and Indirects, instead of the access error. No Oracle write was made.
- **Visual fix:** At the comparison width the record toolbar puts List on row one, Quick Cost through Comments on row two, and Audit Trail and Print on row three. The Budget header places End Date after Start Date in the middle column and Duration first in the last column. The Budget table scrolls horizontally with VBCS-like column widths. AI Summary and Compare Proposal use the VBCS Oracle UX glyphs rather than placeholder characters. Show Year Split uses a compact switch. P_6455 also exposed repeated Oracle cost header IDs; table rows now use their group/category position for a stable React key while keeping the source header ID for actions.
- **Year-split evidence:** On signed-in live DEV P_6455, VBCS and Next.js both showed the 2026, 2027 and 2028 indexed/unindexed period columns and amounts after toggling. The control's role and visual geometry are now aligned. The source `proposals-budget-start-page.html` uses `oj-switch`, and its page function inserts those period columns before Total Cost.
- **Checks:** The focused Budget unit tests passed (7). Typecheck and focused lint passed. The live local DEV P_6455 page loaded with cost rows and the duplicate-key development warning cleared on refresh; no fixture or screenshot alone is being treated as proof of a Budget write. Fixture Chromium and isolated build outcomes are recorded in `docs/progress.md`.
- **Limits:** Budget version rename/create icons and their writes, generated cost line editing beyond the current Staff path, and full role/variant acceptance are separate parity gaps. This change only resolves the observed P_6455 read and layout failures.
- **Switch correction (2026-11-11):** A later user comparison showed the first switch approximation was visibly wrong in the off state. Live VBCS `oj-switch` was measured at 27×15 px, with a 12×12 px rounded thumb, an off track of `#8b8580` and transparent border, and an on track of `#8fbc8f` with a `#315357` border. The local Budget switch now uses those measurements and the source label's 12 px/600 weight. Both states were verified from computed styles in the signed-in VBCS and local P_6455 pages; no Oracle write was made.
- **Thumb alignment follow-up:** The local pseudo-element inherited `translateY(-50%)` from the shared switch rule while its Budget override set `top: 0.5px`, placing the white thumb above the gray track. The Budget override now clears that transform. The local off-state screenshot and computed style show the 12 px thumb within the 15 px track; the checked state retains the same vertical position.
