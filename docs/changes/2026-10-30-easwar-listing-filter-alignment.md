# Align Proposal and Contract listing filters at phone width

- **Date / author / agent:** 2026-10-30 / easwar / Codex
- **Branch / base commit:** codex/proposals-azure-integration-20261030 on aec5020

The Proposal listing puts its inside labels above the Select field and uses full-width filter fields at the same width. The desktop browser comparison also exposed inline Category choices and 12px-inset Proposal fields; Category labels now form separate rows and Proposal fields use the VBCS 6px sidebar inset. Listing-only styles now give LOVs one outline, the Proposal toggle sits in the results toolbar with the shared collapse icon, and the footer is gone while scroll loading remains. `tests/e2e/workspace.spec.ts` checks phone alignment, single-outline fields, toggle behavior, absent page-size control, and desktop Proposal choice spacing.
