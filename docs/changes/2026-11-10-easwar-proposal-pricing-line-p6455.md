# P_6455 Edit Pricing Line correction

- **Date:** 2026-11-10. Active Next.js worktree, uncommitted. VBCS `origin/development` was inspected read-only and signed-in DEV VBCS and Next.js previews were compared at P_6455 (ID 9756).
- **User finding:** the Directly Allocated Edit Pricing Line dialog had no NERC funder row, an empty Eligible Cost field, currency symbols in read-only inputs that VBCS did not use, and different dialog geometry. The missing row also prevented the category/section pencil from offering its funder edit action.
- **VBCS evidence:** the live dialog has a NERC row with £87,180.40 eligible cost, 100.00% eligible, £0.00 contribution, two percentage columns and an edit pencil. Its dialog is two thirds of the 900px preview width, positioned at about 30vh, with a 70px table header and a 96px row. Read-only cost inputs show numbers without a currency symbol, while the table amounts include the symbol. The `origin/development` dialog uses `oj-md-8` and the funder detail table.
- **Changed:** section and category dialogs now aggregate funder detail rows by ID across their cost lines and show edit/save/cancel controls for the scoped funder. Section Eligible Cost is populated. The dialog uses the VBCS width, position, padding, column gaps and table row sizes, with a shorter-viewport fallback. Read-only amount fields format the selected currency value without a symbol; table cells retain the money display. The server now accepts attached Sub-Proposal pricing IDs on the parent Funder Rules write path when at least one row for that ID carries a Proposal number in the freshly authorized Summary. Other record IDs remain forbidden. It rereads Oracle after a successful write.
- **Live DEV acceptance:** Mitchell Carole edited Directly Allocated's NERC row in Next.js and saved the existing zero contribution. The first attempt failed the child-row scope check before the scope fix. The retry succeeded and closed the dialog. A direct URL reload showed the same £87,180.40 eligible cost and £0.00 contribution. This is a real Oracle DEV write on the user-authorized dataset, distinct from fixture tests. No VBCS write was performed for this comparison.
- **Tests:** focused server tests cover attached child rows, cross-record denial and a parent write with a masked attached child. The fixture browser journey checks the grouped dialog's funder row and edit control. Final typecheck, lint, unit suite and isolated production build results appear in `docs/progress.md`.
- **Limit:** this verifies P_6455's section dialog and zero-value Save. It does not establish multi-funder, nonzero-value, category variants or full Proposal parity.
