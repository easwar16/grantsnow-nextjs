# Show finalized Proposal tabs from locked modules

- **Date / author / agent:** 2026-11-03 / easwar / Codex.
- **Branch / base commit:** `codex/proposals-azure-integration-20261030` on `aec5020`.
- **Why:** VBCS marks a tab with a green success icon when `locked_modules` contains that tab's page ID. Next.js showed no marker after finalization. Next.js also rejected empty Summary display values, first Keywords and then Assigned To, while VBCS finalizes from view mode with those controls read-only.
- **What changed:** Proposal tabs now receive the allowlisted page names whose IDs are in the Summary's locked modules and show the success icon for each. Successful Finalize writes refresh the record; the checkbox reconciles its local result with the refreshed server value. The navigation tab sizing and FEC Summary position follow the VBCS tab list. A finalized Summary shows the VBCS lock-status message and finalizing user when the lock belongs to another session. Finalize no longer applies resource-mandatory checks to read-only display fields; the VBCS chain instead checks the rendered validation group and sponsor rules. Fixture coverage checks finalized and unfinalized tabs and the write with empty display fields.
- **Shared pieces used or extended:** Existing Proposal context, `Icon`, Proposal Finalize API, and the allowlisted `getProposalGetLockStatus` operation.
- **Replaces / overrides:** Adds the missing VBCS tab status rendering to the prior Proposal record tab implementation; no framework rule is overridden.
- **Rules touched:** The indicator and attribution follow backend lock state; no client supplied finalization claim is trusted on initial render. The removed display-field gate follows `finalizeProposalSummaryListener.js` (`checkCompleteValidation('vgProposalInfo')`) and the Summary page's view-mode `readonly` bindings. The finalized-by message follows its `lockedBy.msg`, `user_name`, and token comparison.
- **Checks:** Typecheck passed; lint passed with the existing TanStack Virtual warning; 890 unit/integration tests passed; isolated production build passed. After the Assigned To correction, full fixture Playwright had 36 passed, 2 skipped, 1 failure on a Proposal sort-direction timing assertion; that single test passed on rerun. The finalized and unfinalized Proposal tab assertions passed. No live DEV write was sent.
- **Open:** Live DEV finalization was not performed; it needs the designated test dataset and write policy. The VBCS validation group cannot be replicated exactly server-side without an input model for every rendered control; the explicit sponsor and attribute gates remain.
