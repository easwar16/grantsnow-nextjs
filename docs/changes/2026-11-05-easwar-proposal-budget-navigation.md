# Proposal Budget toolbar and costing navigation

- **Date / author / agent:** 2026-11-05 / easwar / Codex
- **Why:** At the half-width preview, the Next.js toolbar pushed Comments, Audit Trail and Print to the right. The Budget tree lacked its VBCS row menu, and Add Cost buttons opened dialogs instead of navigating to subflows.
- **What changed:** List is on its own line; the action group wraps left in button order with each button kept intact. The nested Comments container no longer claims the remaining row width. Staff budget rows use the shared accessible `ActionMenu`. Add Staff, Student, Pool Tech, Non Staff and Research Partner costs link to protected Budget entry routes. Those routes reuse the existing `CostingEditor` and `quickCostOptions`/`saveQuickCost` contract; Save and Cancel navigate back to Budget.
- **Source rule:** VBCS `proposals-budget-start-page.html` displays Add Cost actions by the role expressions. The live VBCS preview showed Add Student Cost even though the corresponding configured `button-labels` entry has `is_visible=N`. This Budget action uses the source role gate and still takes its text from RB. The PI staff-row source menu enables Edit and disables Delete and Clone; Next.js mirrors those controls. The current Edit destination is the protected read-only staff cost detail route and still needs a full edit implementation.
- **Checks:** A live Next.js preview was refreshed at half width and visually compared with the VBCS toolbar; the buttons formed the same three-row pattern. Focused fixture Chromium Budget tests passed (2/2): row menu navigation and staff/nonstaff entry saves. TypeScript, lint (one existing TanStack Virtual warning), whitespace check and the isolated production build passed. No live Oracle mutation was performed.
- **Remaining:** Full VBCS staff/student/pool-tech/nonstaff/research-partner form behavior and existing cost edit/delete/clone workflows need separate implementation and validation. The new entry routes are functional through the existing shared cost API, but do not yet reproduce every VBCS costing field or calculation.
